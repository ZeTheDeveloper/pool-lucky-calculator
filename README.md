# Pocket Calculator

A simple four-function calculator built with Expo and React Native. It runs in Expo Go on iPhone and Android.

## Run on iPhone

1. Install Node.js, then run `npm install` in this folder.
2. Run `npx expo start --tunnel`.
3. Scan the QR code with the Expo Go app on your iPhone. Keep the phone and computer on the same network.

The keypad supports addition, subtraction, multiplication, division, decimals, percentages, sign changes, and deleting the last digit. Division by zero displays an error that can be cleared with `AC`.
